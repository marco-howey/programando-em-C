## Organização

```text
projetos/
└── sorteio_mega/
    ├── README.md
    ├── 1.0/
    ├── 1.5/
    ├── 1.7/
    └── docs/
        ├── FUNCIONALIDADES.md
        └── PROGRESSO.md
```

Cada novo projeto pode ter uma pasta própria dentro de `projetos/`, com um README que explique seu objetivo, como executar e o que falta desenvolver.
